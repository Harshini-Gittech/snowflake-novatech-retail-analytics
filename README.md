# 🏬 Retail Analytics Data Warehouse on Snowflake

An end-to-end Retail Analytics Data Warehouse built on Snowflake, demonstrating modern data warehousing, data ingestion, security, analytical SQL, and Snowflake platform features.

---

# 📌 Project Overview

This project simulates a real-world retail company called **NovaTech Retail**.

**Note:** NovaTech Retail is a fictional company created solely for educational and portfolio purposes.

NovaTech Retail operates both physical retail stores and an online shopping platform. Every day, customer, product, order, and store information is generated from multiple operational systems.

As the business grows, management needs a centralized analytics platform to answer questions such as:

- Which products generate the highest revenue?
- Which stores perform the best?
- Who are the most valuable customers?
- What are monthly sales trends?
- Which product categories are growing fastest?

To solve these challenges, this project builds a complete analytics data warehouse using Snowflake.

---

# 🎯 Project Objectives

- Build a centralized Retail Analytics Data Warehouse
- Load data efficiently into Snowflake
- Implement a Star Schema data model
- Secure data using Role-Based Access Control (RBAC)
- Demonstrate Time Travel and Zero-Copy Cloning
- Create analytical SQL views
- Develop User Defined Functions (UDFs)
- Create Stored Procedures
- Perform data transformations using Snowpark
